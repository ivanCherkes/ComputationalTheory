# Computational Theory Assessment Repo

This repository contains the work completed for the Computational Theory assessment. The goal is to implement and document all the problems for the module.

## Getting started

You will need [Git](https://git-scm.com/) and [Python](https://www.python.org/) installed.

1. Clone this repository:

   ```bash
   git clone https://github.com/ivanCherkes/ComputationalTheory.git
   cd ComputationalTheory
   ```

2. Install the packages listed in [`requirements.txt`](requirements.txt):

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start the notebook:

   ```bash
   jupyter notebook problems.ipynb
   ```

## About the notebook

The notebook is the main working document for the assessment. You can [preview it on GitHub](problems.ipynb) without installing anything, or run it locally by following the setup steps above.
