# Computational Theory Assessment Repo

This repository contains the work completed for the Computational Theory assessment. The goal is to implement and document all the problems for the module.

## Setup instructions:

1. git clone <repo-url>
2. pip install -r requirements.txt
3. jupyter notebook problems.ipynb
